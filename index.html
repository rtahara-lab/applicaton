動作分析アプリ

スマホで撮った動画を、マーカーを貼らずに分析・比較するためのアプリです。目的に合うものを選んでください。インストールは不要で、ブラウザで開くだけで使えます。

スマホで開いています。MotionLab・LongJumpLab・SprintLab は PC での利用をおすすめします（処理が重く、指では点を正確に打ちにくいため）。動画の見比べには MotionCompare が使えます。

MotionLab

いろいろな動作の分析（2次元・3次元）

  • 関節角度・角速度、体幹の捻転角度
  • 指定した部位の変位・速度・加速度
  • ボール等の速度、地面反力の推定、関節トルク
  • スマホ2台で3次元分析、Excel に出力
PC 推奨較正用の基準物が必要
MotionLab を開く

LongJumpLab

走り幅跳びの助走・踏切の分析

  • 助走速度、踏切時の水平速度・鉛直速度
  • 踏切角度、踏切速度、接地時間
  • 重心の高さと軌跡、接地中の沈み込み
  • 横から撮った動画1本で分析、Excel に出力
PC 推奨120fps 以上で撮影
LongJumpLab を開く

SprintLab

短距離走の疾走速度曲線

  • 固定カメラ1台・横からの動画で走者を自動追跡
  • 距離–速度・時間–速度の曲線、5 m／10 m の区間タイム
  • 最高速度とその地点、合図からの反応時間の目安
  • 加速のモデル（vmax・τ）と力–速度プロファイル、試技の比較
PC 推奨スタートとゴールにコーン三脚で固定
SprintLab を開く

MotionCompare

2つの動作を並べて見比べる

  • 2つの動画を左右に並べて表示
  • 起点・終点を指定して局面をそろえる
  • コマ送り、任意の3点で角度を測る
  • 比較画面の画像と角度の CSV を保存
PCスマホ
MotionCompare を開く

使う前に

  • ブラウザ：PC の Google Chrome または Microsoft Edge を使ってください。
  • インターネット：MotionLab と LongJumpLab は、最初の姿勢推定のときに推定エンジンとモデル（合わせて約 25 MB）を読み込みます。SprintLab と MotionCompare はインターネットなしでも動きます。
  • 動画の扱い：動画はブラウザの中だけで処理され、どこにも送信されません。
  • 動画の形式：読み込めないときは H.264 の MP4 に変換してください。iPhone は「設定 → カメラ → フォーマット → 互換性優先」で撮影すると確実です。
  • 使い方：各アプリの「使い方」タブに手順と計算方法があります。
